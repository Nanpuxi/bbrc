# 数据源（DataSource）在本项目中的作用

`dataSources` 是编辑器"存档"（Save）中的一个功能：**让存档引用外部 JSON URL，从中一键导入线
路样式、文本标签图标、纹理、颜色集等资源**。

> 架构说明：前端拆分为 `aarc-core`（编辑器核心）与 `aarc-web`（站点）两个包后，数据源的
> 数据模型、拉取/合并逻辑、配置界面、单元测试全部位于 **aarc-core**；仅开发用示例存档留在
> aarc-web。拆分方案见 `aarc-web/docs/decoupling.md`。

### 数据模型

`aarc-core/src/models/save.ts:247`：

```ts
export interface DataSource {
    id: number
    name?: string
    url: string
    type: 'lineStyles' | 'textTagIcons' | 'patterns' | 'colorSets'
    autoUpdate?: boolean        // 打开存档时自动拉取
    overwriteSameName?: boolean // 同名条目是否覆盖已有项
}
```

存档顶层带可选字段 `dataSources?: DataSource[]`（`save.ts:17`），元数据 `SaveMetaData` 里有
`dataSourcesVersion`（`save.ts:268`）。注意该字段目前**只声明、无消费方**：默认数据源由
`saveNormalize.ts:59` 无条件 `fillDefault` 填充，不走版本判断。后端存档差异同步把它列为
KeyedArray 之一：`AARC.WebApi/Services/Saves/SaveDiffService.cs:86`
（`new KeyedArrayConfig(["dataSources"], false)`），即数据源列表随存档一起保存、
同步、参与增量 diff。

### 核心逻辑：`aarc-core/src/models/save/dataSourceOps.ts`

- `fetchDataSource(url, { isColorSet })`（:16）：fetch URL（经
  `convertToProxyUrlIfNeeded`（`aarc-core/src/utils/urlUtils/proxyUrl.ts:10`）走代理以绕过
  跨域；代理所需的 `apiUrlBase` 来自宿主启动时注入的 `getCoreConfig()`，core 不读
  `import.meta.env`），响应必须是 JSON；大小上限普通类型 64KB（:11）、颜色集 128KB（:12）。
  注意 core 会**直接发出 fetch 请求**，宿主运行环境须放行（见 `aarc-core/README.md`
  "浏览器运行时"一节）。
- `mergeDataSourceItems(save, getNewId, ds, data)`（:58）：要求返回值为**数组**，按 `name`
  去重合并进 `save.lineStyles` / `save.textTagIcons` / `save.patterns`；每项重新分配
  新 id。`overwriteSameName` 开则覆盖同名项，否则跳过。条目数上限 32 个（:13）。
- `mergeColorSourceItems`（:120）/ `applyColorSourceMerges`（:185）：`colorSets` 类型不写入
  存档，而是写入 pinia store `externalColorSets`
  （`aarc-core/src/app/localConfig/externalColorSets.ts`，带 `persist` 持久化到本地），以
  URL 分组（`upsertColorSetGroup`），条目结构为 `{ name, pri, data }`，上限 512 个（:14）。
- `autoUpdateDataSources(save, getNewId, ...)`（:191）：遍历所有 `autoUpdate` 开启的数据源
  逐个拉取合并。

### 打开存档时的自动更新

拆分后 Editor.vue 中原来的 `runAutoUpdateDataSources` 已移除，自动更新收口进 core 的
**会话 API**：`aarc-core/src/app/editorSession.ts:52` 的 `loadSaveIntoEditor` 内部调用
`autoUpdateDataSources`（时序：normalize → 重建派生态 → 数据源自动更新 → 图标加载 →
undo 基线）。宿主侧 `aarc-web/src/pages/editors/Editor.vue` 通过
`loadSaveIntoEditor(raw, { onDataSourceEvent })` 传入事件回调（:165-169、:191-194，
loggers 定义于 :201-211），只负责把加载结果展示给用户，不参与装配顺序。

### 配置界面：`aarc-core/src/components/sidebars/configs/DataSourcesConfig.vue`

侧边栏"数据源"配置区：添加（名称+链接+类型必填，URL 不允许重复，:35）、删除（:60）、单个
"加载"（`loadDataSource`，:100）、"全部重新加载"（:161-166），并可点击切换"自动更新"
"覆盖同名"开关。加载结果（新增/覆盖/跳过/错误计数）就地展示。加载后会按类型触发后续动作：
`textTagIcons` 调 `iconStore.ensureAllLoaded()`，`lineStyles`/`patterns` 调
`envStore.rerender()` 重绘（两个 store 均在 `aarc-core/src/models/stores/`）。

### 颜色集消费侧：`aarc-core/src/components/sidebars/colorPalette.ts`

`loadAndMergeColorSets`（:103-171）把内置颜色集与外部颜色集合并：内置在前，外部按
`save.dataSources` 顺序排列；某数据源开 `overwriteSameName` 时其颜色集覆盖后面所有
同名项，否则同名并存。

### 规范化：`aarc-core/src/models/save/valid/dataSources.ts`

`ensureValidDataSources`（:16，内部 `deduplicateDataSources` :3）按 URL 去重数据源（重复
URL 的条目被移除并告警）。
